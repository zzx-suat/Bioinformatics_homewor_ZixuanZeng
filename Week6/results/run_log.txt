=========== PERMANOVA =========== 
问题: 时间点（before/after）是否解释群落结构？ 
同一受试者贡献两个样本，两者高度相关，故置换必须在受试者内进行。

  Aitchison 距离  R2 = 0.0159 
    无限制置换（错误做法）      p = 0.2770 
    受试者内受限置换（正确做法）p = 0.0180 
    离散度齐性检验 p = 0.2270   （离散度齐，位置差异的解读较安全） 
 
---- UC （58 样本 / 29 受试者）---- 
  Aitchison 距离  R2 = 0.0194 
    无限制置换（错误做法）      p = 0.2760 
    受试者内受限置换（正确做法）p = 0.0220 
    离散度齐性检验 p = 0.3030   （离散度齐，位置差异的解读较安全） 
 
---- 受试者身份的解释力（说明为何必须受限置换）---- 
  Aitchison ~ Subject: R2 = 0.6133, p = 0.0050 
  受试者身份解释了群落方差的很大一部分。这正是把两个时间点当独立样本会失真的原因。 
 
---- 应答组差异：受试者内变化向量 ---- 
  对每个受试者计算 delta = CLR(after) - CLR(before)， 
  再以 delta 向量做 PERMANOVA。每受试者一行，组间观测独立，无需受限置换。 
  ALL  n=64  delta ~ Response: R2 = 0.0160, p = 0.4300 
  IBS  n=35  delta ~ Response: R2 = 0.0382, p = 0.0540
